This page lists videos, guides and community links that help you learn Deployrr and the tools it works with. Material made for older versions is marked.

## Start here for v6

- [Deployrr v6 intro (13 min)](https://youtu.be/Nuo83uzTWco): A short video that shows v6. Watch it before you install.
- [Simple Homelab YouTube channel](https://www.youtube.com/@Simple-Homelab): Tutorial videos and news about new releases.
- [Deployrr website](https://www.simplehomelab.com/deployrr/): The official home of Deployrr.
- [Deployrr on GitHub](https://github.com/SimpleHomelab/Deployrr): The changelog, the list of supported apps, and a place to report problems.

Ready to install? Follow the [quick start](/getting-started/quick-start/). Already installed? See [updating Deployrr](/getting-started/updating-deployrr/).

## Community

- [Deployrr Discord](https://www.simplehomelab.com/discord/): Ask questions and share your setup with other Deployrr users.

## General homelab learning

These cover Docker and tools Deployrr can set up, such as Traefik. They are not specific to one Deployrr version.

- [Traefik Masterclass playlist](https://youtube.com/playlist?list=PL1Hno7tIbSWUGrZSqeB9aCsdAuoeVwvgh): How Traefik is configured and used.
- [Ultimate Docker Server playlist](https://youtube.com/playlist?list=PL1Hno7tIbSWV-c1E87BqTzPMgfGxM08nf): Docker server setup and configuration.
- [UDMS guide series](https://www.simplehomelab.com/tag/ultimate-docker-server/): Written guides on Docker server setup.
- [Proxmox tutorials playlist](https://youtube.com/playlist?list=PL1Hno7tIbSWVrEK7Uibb8WBCN_hjozr_z): Setting up and managing a Proxmox environment.

:::note
The playlists and the UDMS series may include older videos and posts. Menus and screens can differ from what you see in v6.
:::

## Older material (Deployrr v5)

These were made for Deployrr v5. The screens and menus are different in v6, so use them for background only. If you must stay on v5, the [Deployrr README](https://github.com/SimpleHomelab/Deployrr) explains how to get v5.11.2.

- [Deployrr v5 intro (20 min)](https://www.simplehomelab.com/go/deployarr-v5-intro/)
- [Deployrr v5 detailed tutorial (2.5 hours)](https://www.simplehomelab.com/go/deployarr-v5-detailed-guide/)

:::caution
Do not follow install or update steps from v5 videos on a v6 setup. Use the [quick start](/getting-started/quick-start/) instead.
:::
