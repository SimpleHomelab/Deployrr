# Deployrr v6.0.41

Released: 2026-11-03

**If you updated to 6.0.40 and get "Illegal instruction", rerun:**

```bash
sudo npx @simplehomelab/deployrr@latest
```

This hotfix release fixes Deployrr 6.0.40 failing to start with "Illegal instruction" on CPUs without AVX2, such as many Celeron, Pentium, Atom and older systems.

## Install

**npm / npx (Recommended)**, needs Node.js and npm:

```bash
sudo npx @simplehomelab/deployrr@latest
```

**curl** standalone installer, no Node.js or npm needed:

```bash
sudo bash -c "$(curl -fsSL https://files.deployrr.app/install.sh)"
```

Then run `deployrr`.

**Existing users:** see [Action required](#action-required) below before updating.

## Highlights

- **Fixed: "Illegal instruction" on CPUs without AVX2.** Deployrr 6.0.40 did not start on many Celeron, Pentium, Atom and older x86 systems. The x86 binary now runs on any 64-bit x86 CPU again.

## Action required

### You updated to 6.0.40 and Deployrr says "Illegal instruction"

Install Deployrr again to get the fixed binary. Your apps, settings and Docker folder are not changed.

1. Run `sudo npx @simplehomelab/deployrr@latest`. Without Node.js or npm, use the curl installer above instead.
2. Run `deployrr`.

If Deployrr 6.0.40 already works on your system, you don't need to do anything.

## Breaking changes

- None.

## Fixed

- Deployrr failed with "Illegal instruction" on CPUs without AVX2 (many Celeron, Pentium, Atom and older systems). The x86 binary is built for every 64-bit x86 CPU again, and each release is now checked for this before it is published.
